# 🎨 Condomínio Master (Frontend)

Interface administrativa desenvolvida para gestão de carteiras de condomínios, acompanhamento financeiro e controle de inadimplência.

## 🚀 Tecnologias
- **React** (Biblioteca UI)
- **Vite** (Build Tool)
- **Tailwind CSS** (Estilização)
- **Framer Motion** (Animações)
- **Lucide React** (Ícones)
- **Axios** (Integração com API)

## 📁 Estrutura de Pastas
- `src/components`: Componentes reutilizáveis como `KPICard` e `Sidebar`.
- `src/pages`: Telas principais (Dashboard, Rateio, Unidades, Relatórios).
- `src/services`: Configuração da instância do Axios para chamadas à API.
